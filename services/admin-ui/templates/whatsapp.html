Como Configurar
  1. Acesse o Facebook Developers: developers.facebook.com
  2. Crie um app ou use um existente
  3. Adicione o produto WhatsApp Business API
  4. Configure o webhook:
    • URL: https://...
    • Verify Token: Use o mesmo valor configurado acima
    • Webhook Fields: messages, message_deliveries
  5. Obtenha as credenciais:
    • Access Token (permanente)
    • Phone Number ID
    • Business Account ID
